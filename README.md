# CBT B-TEK - Platform Media Pembelajaran Interaktif

Platform penyedia media pembelajaran interaktif berbasis web untuk guru modern di Indonesia.

## 🚀 Fitur Utama
* **Katalog Media Interaktif:** Modul & kuis interaktif Kurikulum Merdeka (Kelas 1 - 6 SD).
* **Super Admin Panel:** Manajemen konten media (upload, edit, hapus) dan pengaturan kuota akses guru.
* **Integrasi Supabase:** Cloud Storage untuk file HTML media interaktif dan PostgreSQL Database.
* **Profil Pengembang:** Informasi pengembang terverifikasi ([budhy92-cyber](https://github.com/budhy92-cyber)).
* **Multi-device & Responsive:** Kompatibel dengan Desktop, Tablet, dan Mobile.

## 📁 Struktur File
* `index.html` - Halaman Beranda (Landing Page & Profil Pengembang)
* `login.html` - Halaman Masuk (Google OAuth & Akun Admin)
* `portal.html` - Halaman Katalog Media Pembelajaran Interaktif
* `admin_3.html` - Panel Pengaturan Super Admin
